# SBA 928 Chauncey Rutledge

A small command-line application for SBA 928, built with Python and `uv`.

## Run

```powershell
uv run sba-928-chauncey-rutledge
```

## Project layout

- `src/sba_928_chauncey_rutledge/` contains the application package.
- `pyproject.toml` defines the project and its command-line entry point.
- `uv.lock` records the resolved environment.
